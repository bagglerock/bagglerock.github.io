02 — Native Mac applications

Photo Library Cleaner

Similar-photo culling for macOS

A native SwiftUI Mac app for picking the keeper out of a burst of near-identical shots, designed so that no comparison can be mistaken for a deletion.

  • Local visual hashing groups similar photos; the single write path to the library is one explicitly confirmed, group-scoped deletion behind a frozen review list.
  • Every decision stays reversible and survives relaunch — active rounds, winners, protected photos, and undo history are all persisted.

Swift 6 · SwiftUI · PhotoKit · StoreKit 2 · XCTest

Personal project · Private repository
